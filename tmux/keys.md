# tmux keybindings

Prefix: `Ctrl-Space`

| Key | Action |
| --- | --- |
| `Prefix` `Prefix` | Send prefix to the app |
| `Prefix h/j/k/l` | Select pane left/down/up/right |
| `Prefix H/J/K/L` | Resize pane by 5 (repeatable) |
| `Prefix \|` | Split horizontally (side by side) |
| `Prefix -` | Split vertically (stacked) |

## Defaults (tmux 3.5a, still active)

Overridden above: `-`, `l`, `L`, `C-b`.

| Key | Action |
| --- | --- |
| `Prefix c` | New window |
| `Prefix &` | Kill window |
| `Prefix ,` | Rename window |
| `Prefix n` / `p` | Next / previous window |
| `Prefix 0-9` | Select window by number |
| `Prefix w` | Choose window from list |
| `Prefix '` | Select window by index |
| `Prefix .` | Move window |
| `Prefix %` | Split horizontally |
| `Prefix "` | Split vertically |
| `Prefix x` | Kill pane |
| `Prefix z` | Zoom pane |
| `Prefix !` | Break pane into new window |
| `Prefix ;` | Last active pane |
| `Prefix o` | Next pane |
| `Prefix q` | Show pane numbers |
| `Prefix {` / `}` | Swap pane up / down |
| `Prefix Arrows` | Select pane by direction |
| `Prefix Ctrl-Arrows` | Resize pane by 1 |
| `Prefix Alt-Arrows` | Resize pane by 5 |
| `Prefix Space` | Next layout |
| `Prefix Alt-1..7` | Preset layouts |
| `Prefix E` | Spread panes evenly |
| `Prefix s` | Choose session |
| `Prefix $` | Rename session |
| `Prefix d` | Detach |
| `Prefix (` / `)` | Previous / next session |
| `Prefix [` | Enter copy mode |
| `Prefix ]` | Paste buffer |
| `Prefix =` | Choose paste buffer |
| `Prefix :` | Command prompt |
| `Prefix ?` | List key bindings |
| `Prefix t` | Clock |
| `Prefix r` | Redraw client |
